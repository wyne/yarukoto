---
title: Keyboard shortcuts
description: Drive Yarukoto on the Mac, Windows and the web from the keyboard.
---

The desktop apps and the web app can be used entirely from the keyboard. On Windows and in a
browser, read ⌘ as **Ctrl**, ⌥ as **Alt** and ⇧ as **Shift**. Every command and its key is also in
the command menu: press **⌘K** and start typing.

Hold **⌘** on its own for a moment and the window labels what it can reach: ⌘1 beside All, ⌘S
on the sidebar button, ⌘, on the gear, and so on. Let go, press a key or click, and the labels go
away.

Keys marked *(Mac)* are only in the Mac app. The Windows app and the web app run in a browser
engine, which keeps those keys for itself (⌘N opens a window, ⌘T a tab, ⌘1 switches tabs), so use
⌘K for those commands there.

In a browser, the text size keys are the browser's own zoom, which does the same job there.

## Moving around the window

The window has four places your keys can go: the **sidebar**, the **add field** at the top of a
list, the **task list**, and the **task pane** open beside it. One of them always has the keyboard. The task list's
current row is tinted in your accent color while the list has it, and in gray while something else
does.

| Key | What it does |
|---|---|
| ⇥ Tab | Next place: sidebar, add field, list, task pane, then round again. The add field passes it on only while empty |
| ⇧⇥ Shift-Tab | The same, backwards |
| ⎋ Escape | Leaves the field you're typing in and gives the keyboard to the list |
| ⌘N | Puts the cursor in the add field *(Mac)* |
| ⌘F | Search, in Browse *(Mac)* |
| ⌘K | Command menu: go to any view, list, folder, tag or saved filter, or run any command |
| ⌘O | Go to a task: search the tasks that aren't done by title, and open the one you pick |
| ⌘1 to ⌘7 | All, Inbox, Agenda, Plan, Activity, Browse, Trash *(Mac)* |
| ⌘S | Show or hide the sidebar, which takes the keyboard as it opens *(Mac)* |
| ⌘D | Show or hide the task pane *(Mac)* |
| ⌘/ | Keyboard shortcuts |
| ⌘= ⌘- | Bigger and smaller text, in steps from 85% to 175% *(Mac and Windows apps)* |
| ⌘0 | Text back to its usual size *(Mac and Windows apps)* |
| ⌘, | Settings *(Mac)* |
| ⌘W | Close the window; with the menu bar icon on, Yarukoto keeps running there *(Mac)* |

## The sidebar

While the sidebar has the keyboard, the row you're on is outlined in your accent color.

| Key | What it does |
|---|---|
| ↑ ↓ | Move through views, lists, folders, filters and tags, showing each as you go, and scrolling to keep the row in view |
| → ← | Open or fold a folder. ← from a list in a folder folds the folder and goes up to it |
| Space | Open or fold the folder you're on |
| ↩ Return, ⎋ Escape or → | Back to the task list |

## The task list

| Key | What it does |
|---|---|
| ↑ ↓, or j k | Move between tasks |
| ⌘↑ ⌘↓, Home and End, or gg G | First and last task |
| Page Up, Page Down | Move ten tasks at a time |
| } { | Next group, or back to the start of this group and then the one before |
| ⌃E ⌃Y | Scroll a row down or up. The current row stays put until it would leave the screen |
| za | Fold or unfold the current group |
| zc zo | Fold, or unfold, the current group |
| zM zR | Fold, or unfold, every group |
| i or o | Put the cursor in the add field: the web's New Task, where the browser keeps ⌘N |
| / | Search, in Browse: the web's Find, where the browser keeps ⌘F |
| `\` | Show or hide the sidebar: the web's ⌘S, which the browser keeps |
| ⇧↑ ⇧↓ | Select several tasks |
| ↩ Return | Open the task and start editing its title |
| Space | Open the task beside the list, keeping the keyboard on the list |
| → | Into the task pane, opening the task if it isn't |
| ← | To the sidebar |
| ⎋ Escape | Clear the selection, then close the task pane |
| ⌘↩ | Mark as done |
| ⌘T | Due today *(Mac)* |
| ⌥⌘T | Due tomorrow |
| ⌥⌘1, ⌥⌘2, ⌥⌘3, ⌥⌘0 | Priority high, medium, low, none |
| ⇧⌘M | Move to a list: pick one in the command menu *(Mac)* |
| ⇧⌘T | Add or remove tags: pick them in the command menu *(Mac)* |
| ⌘⌫ | Move to Trash. A plain ⌫ only shows this reminder, so a key meant to fix a typo can't trash a task |
| ⌘Z | Undo the last complete or delete, while its notice is showing *(Mac)* |

With several tasks selected, the task keys act on all of them.

The letter keys follow vim, and like every task list key they only reach the list while it has the
keyboard: typing **j** in the add field or a task's title types a j. For **gg** and the **z** keys,
press the second key within a second of the first. ⌃E and ⌃Y are **Ctrl+E** and **Ctrl+Y** on
Windows and in a browser too.

A folded group is a stop of its own as you move through the list: its header takes the tint, so
**za**, **zo**, **Space** or **Return** opens it again. Unfolding a group from its header puts you on its first task.

Press **⌘/** to open the complete keyboard shortcut reference. Search it by action, area, or key —
for example, **due**, **task**, **cmd t**, or **option command t**.

In the command menu, a list, folder or tag is always **Go to**: choosing it opens it. To put the
selected tasks in a list or tag them instead, choose **Move to List…** or **Edit Tags…** there, which
turns the menu into a picker. In Edit Tags, Return adds the tag or, when every selected task has it
already, removes it; type a new name to make a new tag.

Commands that change a selected task's due date or priority begin with **Set**, distinguishing them
from places beginning with **Go to**. These prefixes are searchable, so typing **go to** lists every
place you can open.

To group or sort the list in front, type **group** or **sort** in the command menu (⌘K), or use
**View ▸ Group By** and **View ▸ Sort By** in the Mac menu bar, where the one in use is checked.

## The add field

| Key | What it does |
|---|---|
| ↩ Return | Add the task and stay in the field for the next one |
| ↓ | While suggestions are showing, ↑ and ↓ move through them. In an empty field, go down into the list |
| ⇥ Tab | Complete the tag, list or priority being typed with the highlighted suggestion, or the first one if none is highlighted. In an empty field, move on to the list |
| ⇧⇥ Shift-Tab | In an empty field, back to the sidebar |
| ⎋ Escape | Give the keyboard to the list, keeping whatever you've typed |

While there's text in the field, ↓, Tab and Shift-Tab never move you out of it: with nothing to
complete, Tab does nothing. So the keyboard can't end up on the list mid-sentence, where the next
key would act on a task. **Escape** is the way out with a draft half-typed.

So a quick capture is **⌘N**, type, **Return**, and **↓** or **Escape** to get back to the list.

## Editing a task

| Key | What it does |
|---|---|
| ⇥ Tab | Next field: title, notes, each subtask, then the add-subtask field |
| ⇧⇥ Shift-Tab | Previous field |
| ↩ Return in the title | Jump to the notes |
| ⌘B, ⌘I | Bold and italic, in the notes |
| ⎋ Escape | Back to the list, with the task still open |

Tab past the last field moves on to the sidebar; Shift-Tab from the title goes back to the list.
