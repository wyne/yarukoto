---
title: Keyboard shortcuts
description: Drive Yarukoto on the Mac, Windows and the web from the keyboard.
---

The desktop apps and the web app can be used entirely from the keyboard. On Windows and in a
browser, read ⌘ as **Ctrl**, ⌥ as **Alt** and ⇧ as **Shift**. Every command and its key is also in
the command menu: press **⌘K** and start typing.

Keys marked *(Mac)* are only in the Mac app. The Windows app and the web app run in a browser
engine, which keeps those keys for itself (⌘N opens a window, ⌘T a tab, ⌘1 switches tabs), so use
⌘K for those commands there.

## Moving around the window

The window has three places your keys can go: the **add field** at the top of a list, the **task
list**, and the **task pane** open beside it. One of them always has the keyboard. The task list's
current row is tinted in your accent color while the list has it, and in gray while something else
does.

| Key | What it does |
|---|---|
| ⇥ Tab | Next place: add field, then list, then task pane, then round again |
| ⇧⇥ Shift-Tab | The same, backwards |
| ⎋ Escape | Leaves the field you're typing in and gives the keyboard to the list |
| ⌘N | Puts the cursor in the add field *(Mac)* |
| ⌘F | Search, in Browse *(Mac)* |
| ⌘K | Command menu: go to any view, list, folder, tag or saved filter, or run any command |
| ⌘1 to ⌘7 | All, Inbox, Today, Calendar, Activity, Browse, Trash *(Mac)* |
| ⌘, | Settings *(Mac)* |

## The task list

| Key | What it does |
|---|---|
| ↑ ↓ | Move between tasks |
| ⇧↑ ⇧↓ | Select several tasks |
| ↩ Return, or ⌘O | Open the task in the pane |
| ⎋ Escape | Clear the selection, then close the task pane |
| ⌘↩ | Mark as done |
| ⌘T | Due today *(Mac)* |
| ⌥⌘T | Due tomorrow |
| ⌥⌘1, ⌥⌘2, ⌥⌘3, ⌥⌘0 | Priority high, medium, low, none |
| ⌫ Delete | Move to Trash |
| ⌘Z | Undo the last complete or delete, while its notice is showing *(Mac)* |

With several tasks selected, the task keys act on all of them.

## The add field

| Key | What it does |
|---|---|
| ↩ Return | Add the task and stay in the field for the next one |
| ↓ | Go down into the list. While suggestions are showing, ↑ and ↓ move through them |
| ⇥ Tab | Take the highlighted suggestion, or move on to the list |
| ⎋ Escape | Give the keyboard to the list |

So a quick capture is **⌘N**, type, **Return**, and **↓** or **Escape** to get back to the list.

## Editing a task

| Key | What it does |
|---|---|
| ⇥ Tab | Next field: title, notes, each subtask, then the add-subtask field |
| ⇧⇥ Shift-Tab | Previous field |
| ↩ Return in the title | Jump to the notes |
| ⌘B, ⌘I | Bold and italic, in the notes |
| ⎋ Escape | Back to the list, with the task still open |

Tab past the last field moves on to the add field; Shift-Tab from the title goes back to the list.
